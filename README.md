# Secretario — Sofi, la asistente de mamá

Asistente personal en Grok Bot, con línea de WhatsApp propia, para ayudar a mamá con salud, agenda, compras, mails y mensajes.

## Por dónde empezar
1. [`PLAN-3-DIAS.md`](PLAN-3-DIAS.md) — **empezá acá.** Checklist día por día.
2. [`FICHA-MAMA.md`](FICHA-MAMA.md) — datos a completar antes del Día 1.
3. [`guia-secretaria-mama.md`](guia-secretaria-mama.md) — la guía completa y el **prompt inicial**.
4. [`MENSAJES-PARA-SOFI.md`](MENSAJES-PARA-SOFI.md) — mensajes listos para copiar y pegar, en orden.
5. [`COMO-USAR-SOFI.md`](COMO-USAR-SOFI.md) — machete para imprimir y dejarle a mamá.

> ⚠️ Este repo no tiene que tener datos reales de mamá (teléfonos, medicación, n.º de afiliada). Completá la ficha en papel o en una copia privada.
